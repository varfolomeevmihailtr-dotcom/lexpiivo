# LEX PIIVO — бесплатная общая база (проект)
Этот файл — подготовленная миграция для Supabase. **База пока не создана и сайт к ней не подключён.**
Не запускать миграцию на существующем проекте без проверки таблиц и политик.
1. Создать отдельный проект на Supabase Free.
2. Запустить `001_lex_schema.sql` в SQL Editor.
3. Подключить Supabase к ChatGPT, чтобы завершить настройку.
4. Добавить URL проекта и **publishable/anon key** в конфигурацию сайта. **Никогда** не публиковать service_role или secret key.
5. Настроить Auth redirect URL для GitHub Pages, подтверждение email, правила регистрации, роль первого администратора.
6. Реализовать интерфейс входа, синхронизацию прогресса, запись на гонку и модерацию инцидентов.
7. Перед включением синхронизации предусмотреть согласие игрока и экспорт существующего локального профиля.

### Модель
- `lex_profiles`: игровой ник и роль player/officer/admin.
- `lex_player_progress`: личный прогресс (JSON), доступен только владельцу.
- `lex_race_sessions`: гонки по датам, слотам 14:00 и 23:00, с явной временной зоной.
- `lex_race_signups`: запись на один или оба слота.
- `lex_incidents`: проверяемые инциденты с возможностью оспаривания и исправления.
RLS включена; офицеры создают события и инциденты. Ник не доказывает владение игровым аккаунтом.
