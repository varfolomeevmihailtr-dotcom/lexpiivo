# [LEX]PIIVO — Штаб сервера 347

**[Открыть сайт](https://varfolomeevmihailtr-dotcom.github.io/lexpiivo/LEX-PIIVO-site/#home)**

[Короткий адрес](https://varfolomeevmihailtr-dotcom.github.io/lexpiivo/) — перенаправляет в рабочую папку сайта после публикации обновления GitHub Pages.

## Возможности
- Герои, состав отряда, навыки и экипировка
- Калькуляторы прокачки, звёзд и ресурсов
- Гайды, календарь сервера, события и промокоды
- Личный прогресс в браузере; экспорт и импорт JSON через «Мой прогресс»
- Ненавязчивые реплики героев, которые можно выключить кнопкой ✦

## Для игроков
Данные сохраняются **только на устройстве**. Для переноса и резервной копии перейдите в «Мой прогресс» и используйте «Экспорт». Не удаляйте данные браузера, пока не скачаете копию.

## Для администраторов
Основной сайт находится в `LEX-PIIVO-site/`. Ветка публикации — `main`, в настройках Pages требуется `Deploy from a branch / main / (root)`. Из корневого `index.html` настроено перенаправление на сайт. Никакой сервер или база данных не используются.
